# 🎨 Prompt Generator

A simple GUI tool for generating Stable Diffusion prompts.

## 🚀 Features

* Random prompt generation
* Lock specific attributes
* NSFW control levels
* Lighting & cinematic presets
* Easy copy for ComfyUI / A1111


## 🚀 Quick Start

```bash
git clone https://github.com/kv850729/prompt-generator.git
cd prompt-generator
python3 prompt_generator_safe_v1.py

```

## 📦 Requirements

* Python 3.10+

## 📁 Files

* prompt_generator_safe_v1.py → main program
* prompt_config_safe_v1.json → config data

## 🧠 Notes

* Press `Space` to regenerate prompts
* Lock options to keep selected attributes
