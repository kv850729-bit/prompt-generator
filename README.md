# 🎨 Prompt Generator

A simple GUI tool for generating Stable Diffusion prompts.

## 🚀 Features

* Random prompt generation
* Lock specific attributes
* NSFW control levels
* Lighting & cinematic presets
* Easy copy for ComfyUI / A1111

## 🖥️ Usage

## 🚀 Quick Start

```bash
git clone https://github.com/你的帳號/prompt-generator.git
cd prompt-generator
python3 prompt_generator_v22.py

```bash
python3 prompt_generator_v22.py
```

## 📦 Requirements

* Python 3.10+

## 📁 Files

* prompt_generator_v22.py → main program
* prompt_config_v22.json → config data

## 🧠 Notes

* Press `Space` to regenerate prompts
* Lock options to keep selected attributes
